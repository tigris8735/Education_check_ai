# Бизнес-требования

## 1. Обзор проекта

**EduCheck AI** — веб-приложение для преподавателей и студентов, которое упрощает проверку учебных работ с помощью искусственного интеллекта, структурирует группы и хранит данные в отдельной базе данных.

Система построена на микросервисной архитектуре, деплоится на **Render**, использует **Neon** в качестве облачной PostgreSQL-базы. Стек: Python, JavaScript, CSS, HTML.

## 2. Цели проекта

### 2.1. Бизнес-цели
- Сократить время преподавателя на проверку типовых работ.
- Автоматизировать первичную оценку и формирование обратной связи.
- Обеспечить прозрачное хранение работ, оценок и комментариев.
- Дать студентам быструю обратную связь по загруженным работам.

### 2.2. Пользовательские цели
- Преподавателю — быстро создавать задания, группы и проверять работы.
- Студенту — загружать работы и получать предварительный AI-разбор.
- Администратору — управлять пользователями и ролями.

## 3. Решаемые проблемы

### 3.1. Основные проблемы
- **Ручная проверка** большого количества однотипных работ занимает много времени.
- **Разрозненность данных** — работы, оценки и группы хранятся в разных местах.
- **Задержка обратной связи** — студент долго ждёт комментариев преподавателя.
- **Субъективность** первичной проверки при большом объёме.

### 3.2. Решение EduCheck AI
- **AI-проверка** — автоматический анализ текста работы по критериям.
- **Группы и роли** — преподаватели, студенты, администраторы.
- **Задания и сдачи** — централизованное хранение работ.
- **Облачная БД Neon** — надёжное хранение данных.
- **Деплой на Render** — быстрый доступ через браузер.

## 4. Целевая аудитория

| Группа | Описание | Основные потребности |
|--------|-----------|---------------------|
| **Преподаватели** | Проверяют работы, ведут группы | Быстрая проверка, критерии, комментарии |
| **Студенты** | Загружают работы, получают feedback | Понятные требования, быстрая обратная связь |
| **Администраторы** | Управляют пользователями и доступами | Роли, безопасность, отчётность |

## 5. Основные возможности

### 5.1. High-Level Features
1. **Управление пользователями и ролями**
   - Регистрация/вход по JWT.
   - Роли: `TEACHER`, `STUDENT`, `ADMIN`.

2. **Управление группами**
   - Создание групп преподавателем.
   - Добавление студентов в группы.
   - Просмотр состава и заданий группы.

3. **Задания и работы**
   - Создание задания с описанием и критериями.
   - Загрузка работы студентом (текст/файл).
   - Статусы: `DRAFT`, `SUBMITTED`, `AI_CHECKED`, `REVIEWED`.

4. **AI-проверка**
   - Отправка текста работы в AI-сервис.
   - Получение предварительной оценки и комментариев.
   - Сохранение результата в БД.

5. **Обратная связь и отчёты**
   - Преподаватель видит AI-разбор и выставляет итоговую оценку.
   - Студент видит комментарии и статус проверки.

## 6. Критерии успеха

### 6.1. Количественные метрики
- 80%+ типовых работ получают AI-разбор без ручного вмешательства.
- Время первичной AI-проверки — < 10 секунд на работу.
- Поддержка 10+ одновременных пользователей.
- Доступность сервиса — 95%+ при работающих Render и Neon.

### 6.2. Качественные метрики
- Понятный интерфейс для преподавателя и студента.
- Корректное разделение прав доступа.
- Прозрачные критерии AI-проверки.
- Стабильная работа микросервисов на Render.
