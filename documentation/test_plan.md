# План тестирования

## 1. Стратегия тестирования

### 1.1. Общий подход
Тестирование EduCheck AI фокусируется на:
- корректности микросервисного взаимодействия;
- безопасности ролей и JWT;
- качестве AI-проверки;
- стабильности деплоя на Render и Neon.

### 1.2. Уровни тестирования
- **Модульное тестирование**: сервисы, валидация, БД.
- **Интеграционное тестирование**: API Gateway <-> микросервисы, AI Check <-> LLM.
- **Системное тестирование**: полный цикл от создания задания до проверки.
- **Приёмочное тестирование**: удобство для преподавателя и студента.

## 2. Объекты тестирования

### 2.1. Ключевые модули

#### **Auth Service**
- Регистрация, вход, JWT.
- Роли и доступ.

#### **Group Service**
- Создание групп, добавление студентов.
- Связь с заданиями.

#### **Assignment Service**
- Создание заданий.
- Загрузка работ.
- Статусы и оценки.

#### **AI Check Service**
- Формирование промпта.
- Вызов LLM API.
- Парсинг и сохранение результата.

#### **Frontend**
- Формы и дашборды.
- Отображение AI-разбора.
- Работа с API Gateway.

#### **Инфраструктура**
- Render Web Services.
- Neon PostgreSQL.
- Переменные окружения.
